# Factory Quality Radar

라인별 다음날 품질 검사 불량률을 예측하고 운영 조건을 직접 조작해 보는 제조 AI 체험형 프로젝트입니다.

## 실행

```powershell
python -m streamlit run app.py
```

브라우저에서 표시되는 앱은 다음 네 페이지로 구성됩니다.

1. **문제 정의**: 왜 사전 품질 리스크 예측이 필요한지 설명
2. **AI 해결 설계**: 입력 데이터, 타깃, 모델 동작 방식 설명
3. **직접 체험하기**: 비가동률·생산량·양품률·에너지를 조절해 AI 예측을 즉시 비교
4. **검증과 한계**: 시간 순서 검증 성능과 데이터 한계 설명
5. **AI 챗봇에게 묻기**: 자연어로 조건을 바꾸면 로컬 회귀 모델을 실행하고 GPT가 결과를 설명

가동률·품질검사 공통 기간을 사용합니다. 센서 데이터와 가동률 데이터의 기간은 겹치지 않아, 현재 버전에서는 함께 학습에 사용하지 않습니다.

## 모델 설계

- 타깃: 다음 달력일의 라인별 품질 검사 불량률 (`defect_qty / insp_qty`)
- 입력: 당일 불량률/최근 불량률, 가동 가능률, 비가동률, 생산량, 양품률, 에너지 효율, 비가동 사유별 시간
- 검증: 미래 구간을 테스트로 둔 시간 순서 hold-out
- 비교: 당일 불량률 기준 모델, Ridge 회귀, Random Forest 회귀

작은 표본 기반의 탐색적 모델이므로 예측값은 점검 우선순위를 정하는 참고 지표로 사용해야 합니다.

## GPT 챗봇 설명 기능 (선택)

API 키 없이도 자연어 조건 해석과 로컬 회귀 모델 시뮬레이션은 동작합니다. GPT가 결과를 자연어로 설명하게 하려면 환경 변수에 API 키를 설정한 뒤 앱을 실행합니다.

```powershell
$env:OPENAI_API_KEY="your_api_key"
# 선택: 접근 가능한 모델로 변경
$env:OPENAI_MODEL="gpt-5.6"
python -m streamlit run app.py
```

챗봇은 수율/불량률을 직접 산출하지 않습니다. 질문의 조건을 제한된 모델 입력으로 해석하고, 로컬 Random Forest 회귀 모델이 계산한 결과만 설명합니다. OpenAI API는 Responses API로 연결됩니다.
