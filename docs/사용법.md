# 사용법 — 돼지 저금통 공장 라인 3D 시뮬레이터

제품이 하나 완성될 때마다 **완성 카운터가 올라가고, 그 순간의 센서 9종 값이 그대로 기록**됩니다.
"몇 개 만들었나"뿐 아니라 **"3번째 제품이 만들어질 때 온도가 몇이었나"**까지 되짚어 볼 수 있습니다.

---

## 1. 실행

프로젝트 폴더에서 로컬 서버를 띄운 뒤 브라우저로 접속합니다.

```bash
python serve.py
```

`serve.py` 가 서버를 띄우고 브라우저를 자동으로 엽니다. 직접 띄우려면:

```bash
python -m http.server 8000
```

접속 주소는 <http://localhost:8000> 입니다.

> ### ⚠️ `index.html` 을 더블클릭하면 3D가 뜨지 않습니다
>
> 이 페이지는 `piggy-line.js` 를 ES 모듈(`<script type="module">`)로 불러옵니다.
> ES 모듈은 `file://` 로 열면 브라우저 CORS 정책에 막혀 로드 자체가 되지 않습니다.
>
> ```
> Access to script at 'file:///.../piggy-line.js' from origin 'null'
> has been blocked by CORS policy
> ```
>
> 코드 문제가 아니라 브라우저 보안 정책이므로, **반드시 위처럼 로컬 서버로 띄워야 합니다.**
> three.js 는 CDN(unpkg)에서 받아오므로 최초 실행 시 인터넷 연결이 필요합니다.

## 3. 제품 카운트

| 카운터 | 올라가는 시점 |
|---|---|
| **사이클** | 사이클이 시작될 때 (`▶ 정상 사이클 실행` / `⚠ 경고 사이클`) |
| **완성** | 제품이 포장 라인을 통과해 적재될 때 (사이클 시작 후 약 14.9초) |
| **불량** | 임계값 초과로 라인이 멈추고 리젝트 빈으로 배출될 때 |

`▶ 정상 사이클 실행` 을 누르면 약 16.6초 주기로 **자동 반복**되므로, 두면 완성 카운트가 계속 쌓입니다.

## 4. 제품별 센서 값 확인하기 — `04 제품 생산 이력`

완성(또는 불량 배출)이 확정되는 순간 센서 9종 값이 통째로 캡처되어 카드로 쌓입니다. **최신이 맨 위**입니다.

```
┌───────────────────────────────────────────────────────┐
│ #2  [불량]                        사이클 3 · 15:04:20 │
│                                                       │
│ 온도센서       압력센서         진동센서              │
│ 272 °C         88 bar           12.1 mm/s ▲          │  ← 빨간색 + ▲ = 임계 초과
│                                                       │
│ 습도센서       사이클타임 센서   두께 계측기           │
│ 37 %RH         18 s             2.9 mm                │
│                                                       │
│ 경도 계측기    전력량계 센서     가동/정지 타이머      │
│ 68 Shore D     52 kW            237 min               │
└───────────────────────────────────────────────────────┘
```

카드 읽는 법:

- **`#번호`** — 제품 일련번호. 완성·불량을 합쳐 기록된 순서대로 매겨집니다.
- **판정 태그** — `양품`(검은색) 또는 `불량`(빨간색). 불량 카드는 왼쪽 테두리도 빨간색입니다.
- **사이클 N · 시각** — 몇 번째 사이클에서, 몇 시 몇 분에 나온 제품인지.
- **센서 9종 값** — 그 제품이 만들어지던 순간의 값. 단위까지 함께 표시됩니다.
- **빨간 값 + `▲`** — 그 시점에 임계값을 벗어나 있던 센서. 불량의 원인을 바로 짚을 수 있습니다.

최근 **100건**까지 보관하며, 그보다 오래된 기록은 자동으로 밀려납니다.

### 초기화

`⟲ 초기화` 를 누르면 카운터 3종과 **생산 이력이 모두 지워집니다.** 센서 값도 기본값으로 되돌아갑니다.
(`⚠ 경고 사이클` 은 카운터와 이력을 지우지 않고 이어서 기록합니다.)

## 5. 이력을 엑셀로 옮기기

`04` 섹션 우측의 **`이력 복사`** 버튼을 누르면 전체 이력이 **TSV(탭 구분)** 형식으로 클립보드에 복사됩니다.
엑셀·구글 시트에 그대로 붙여넣으면 표로 들어갑니다.

```
제품번호	판정	사이클	시각	온도센서(°C)	압력센서(bar)	진동센서(mm/s)	...
2	불량	3	15:04:20	272	88	12.1	...
1	양품	1	15:04:20	214	88	4.2	...
```

> 클립보드 접근이 막힌 환경에서는 버튼이 `복사 실패` 로 바뀝니다. 그때는 아래 콘솔 API를 쓰세요.

## 6. 콘솔에서 데이터 꺼내기

브라우저 개발자도구(F12) 콘솔에서 바로 호출할 수 있습니다.

| 함수 | 반환값 |
|---|---|
| `PLANT_LOG()` | 전체 이력 배열 (최신순). 각 항목에 `no` `result` `cycle` `time` `sensors[9]` |
| `PLANT_LOG_TSV()` | 위 이력을 TSV 문자열로 |
| `PLANT_FEED()` | **현재** 센서 9종의 값 (이력이 아닌 실시간 스냅샷) |

`sensors` 배열 한 항목의 구조:

```js
{
  id: 'vibration',        // 센서 식별자
  label: '진동센서',       // 화면 표시 이름
  unit: 'mm/s',           // 단위
  value: 12.1,            // 이 제품이 만들어질 때의 값
  threshold: 12,          // 상한 임계값
  thresholdLow: null,     // 하한 임계값 (두께 계측기만 2.0, 나머지는 null)
  exceeded: true          // 이 시점에 임계를 벗어나 있었는가
}
```

활용 예 — 완성된 제품들의 평균 온도:

```js
const good = PLANT_LOG().filter(e => e.result === '양품');
const avg = good.reduce((a, e) => a + e.sensors.find(s => s.id === 'temp').value, 0) / good.length;
console.log('양품 평균 온도', avg.toFixed(1), '°C');
```

활용 예 — 불량 제품에서 임계를 넘긴 센서만 모아 보기:

```js
PLANT_LOG()
  .filter(e => e.result === '불량')
  .forEach(e => console.log('#' + e.no, e.sensors.filter(s => s.exceeded).map(s => `${s.label}=${s.value}${s.unit}`)));
```

## 7. 센서 9종과 임계값

| 그룹 | 센서 | 단위 | 범위 | 임계값 | 기본값 |
|---|---|---|---|---|---|
| 01 실시간 공정 | 온도센서 | °C | 150–320 | 280 초과 | 214 |
| 01 | 압력센서 | bar | 40–160 | 132 초과 | 88 |
| 01 | 진동센서 | mm/s | 0–20 | 12 초과 | 4.2 |
| 01 | 습도센서 | %RH | 10–90 | 68 초과 | 37 |
| 01 | 사이클타임 센서 | s | 8–40 | 30 초과 | 18 |
| 02 품질·물성 | 두께 계측기 | mm | 1–6 | 4.4 초과 **또는 2.0 미만** | 2.9 |
| 02 | 경도 계측기 | Shore D | 40–100 | 88 초과 | 68 |
| 03 설비·가동 | 전력량계 센서 | kW | 0–120 | 96 초과 | 54 |
| 03 | 가동/정지 타이머 | min | 0–600 | 480 초과 | 226 |

**두께 계측기만 상·하한을 모두 봅니다.** 나머지는 상한만 넘기면 경고입니다.

## 8. 직접 불량을 만들어 보기

1. `▶ 정상 사이클 실행` 으로 라인을 돌립니다.
2. 우측 센서의 **슬라이더를 임계값 위로** 끌어 올립니다. (예: 진동센서를 13 이상으로)
3. 즉시 라인이 멈추고(`경고 · 라인 정지`), 리젝트 빈으로 배출되며 **불량 카운터가 1 올라갑니다.**
4. `04 제품 생산 이력` 맨 위에 불량 카드가 생기고, 방금 올린 센서가 **빨간색 + ▲** 로 표시됩니다.

`⚠ 경고 사이클` 버튼은 이 과정을 자동으로 재현합니다 — 사이클 도중 온도와 진동이 함께 치솟습니다.

## 10. 파일 구성

```
workshop_piggyFactory/
├── index.html              페이지 본체 (마크업 + 페이지 전용 스타일 + three.js 임포트맵)
├── css/styles.css          디자인 시스템 토큰 · 공통 컴포넌트 스타일
├── js/
│   ├── three-d-stage.js    <three-d-stage> 커스텀 엘리먼트 — 렌더러·조명·카메라·내보내기
│   ├── piggy-line.js       라인 3D 모델 · 사이클 애니메이션 · 센서 패널 · 생산 이력
│   └── plant-overview.js   경고 3초 후 슬라이드 인 되는 공장 전경 패널
├── docs/사용법.md          이 문서
└── serve.py                로컬 서버 실행 스크립트
```

생산 이력 기능은 `js/piggy-line.js` 의 `snapshot()` · `renderLog()` 에 있고,
완성 카운트 지점(`t > 14.9`)과 불량 배출 지점에서 각각 호출됩니다.
