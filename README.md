# 돼지 저금통 공장 라인 3D 시뮬레이터

사출 → 유약 도장 → 두께·경도 계측 → 포장까지 이어지는 라인을 three.js 로 3D 재현하고,
센서 9종을 실시간으로 표시하는 브라우저 페이지입니다.

**제품이 하나 완성될 때마다 완성 카운터가 올라가고, 그 순간의 센서 9종 값이 그대로 기록됩니다.**
임계값을 넘긴 센서는 빨간색으로 표시되어 불량의 원인을 바로 짚을 수 있습니다.

## 실행

```bash
python serve.py
```

브라우저가 자동으로 열립니다. `python -m http.server 8000` 으로 띄워도 됩니다.

> ⚠️ **`index.html` 더블클릭은 동작하지 않습니다.** ES 모듈이 `file://` 에서 CORS 정책에 막힙니다.
> 반드시 로컬 서버로 띄우세요. 자세한 이유는 [docs/사용법.md](docs/사용법.md#1-실행) 참고.

three.js 는 CDN(unpkg)에서 받아오므로 최초 실행 시 인터넷 연결이 필요합니다.

### 링크로 공유하려면

저장소 `Settings → Pages` 에서 소스를 `main` 브랜치 `/ (root)` 로 지정하면 GitHub Pages 로 바로 열립니다.
정적 파일뿐이라 빌드 설정이 필요 없고, https 로 서빙되므로 위의 CORS 문제도 생기지 않습니다.

## 조작

| 버튼 | 동작 |
|---|---|
| `▶ 정상 사이클 실행` | 약 16.6초 주기로 자동 반복. 완성 카운트가 계속 쌓입니다 |
| `⚠ 경고 사이클` | 사이클 도중 온도·진동이 치솟아 불량 배출까지 재현 |
| `⟲ 초기화` | 카운터 3종 + 생산 이력 + 센서값을 모두 되돌림 |

우측 패널의 슬라이더로 센서를 직접 임계값 위로 올려 불량을 만들어 볼 수도 있습니다.
3D 뷰는 드래그로 회전, 휠로 확대, 우클릭 드래그로 이동합니다.

## 제품별 센서 값 확인

우측 패널 `04 제품 생산 이력` 섹션에 제품이 카드로 쌓입니다 (최신순, 최대 100건).

- `#번호` · 판정(`양품`/`불량`) · 사이클 번호 · 시각
- 그 제품이 만들어지던 순간의 **센서 9종 값 전부**
- 임계를 벗어난 센서는 **빨간색 + ▲**

`이력 복사` 버튼으로 전체 이력을 TSV로 복사해 엑셀에 붙여넣을 수 있고,
콘솔에서 `PLANT_LOG()` · `PLANT_LOG_TSV()` · `PLANT_FEED()` 로도 꺼낼 수 있습니다.

전체 사용법과 센서별 임계값 표는 **[docs/사용법.md](docs/사용법.md)** 에 정리했습니다.

## 구성

```
workshop_piggyFactory/
├── index.html              마크업 + 페이지 전용 스타일 + three.js 임포트맵
├── css/styles.css          디자인 시스템 토큰 · 공통 컴포넌트
├── js/
│   ├── three-d-stage.js    <three-d-stage> — 렌더러 · 조명 · 카메라 · OBJ/GLB 내보내기
│   ├── piggy-line.js       라인 모델 · 사이클 애니메이션 · 센서 패널 · 생산 이력
│   └── plant-overview.js   경고 3초 후 슬라이드 인 되는 공장 전경 패널
├── docs/사용법.md          사용법 전문
└── serve.py                로컬 서버 실행
```

의존성은 three.js r184 하나이며 CDN에서 불러옵니다. 별도 빌드 과정이 없습니다.
